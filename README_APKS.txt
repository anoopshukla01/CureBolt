How to Install:
-------------------------------------------------------------
Option A: Android Studio Emulator (Easiest)
  - Start any Android emulator in Android Studio.
  - Simply DRAG AND DROP any of the .apk files from this folder onto the emulator screen.
  - Android will immediately install and show the app on the home screen.

Option B: Physical Android Device via ADB
  Run from terminal:
    adb install -r CureBolt_Customer_App.apk
    adb install -r CureBolt_Rider_Fleet_App.apk
    adb install -r CureBolt_Pharmacy_Counter_App.apk
    adb install -r CureBolt_Admin_Operations_Hub.apk

Option C: Direct Transfer
  - Send the .apk file to your Android phone via WhatsApp, Google Drive, or USB cable.
  - Tap the file to install (allow "Install from Unknown Sources" if prompted).
